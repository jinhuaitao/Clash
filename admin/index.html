绑定 KV 存储

    
管理操作需要持久化配置。项目已内置自动绑定，通常无需任何手动步骤。

    
    
      
  1. 1
    确认 wrangler.toml 中的绑定声明
    仓库内 wrangler.toml 已声明 [[kv_namespaces]]，绑定名固定为 SUB_KV，且不写 id。
    2. 
      
  2. 2
    重新部署即可自动创建并绑定
    Cloudflare 连接 GitHub 后，每次推送都会执行 wrangler deploy，此时 Wrangler 会自动创建（或复用）KV 命名空间并完成绑定。
    3. 
      
  3. 3
    若仍提示未绑定
    在「存储和数据库 → KV」手动创建一个命名空间，把它的 ID 填到 wrangler.toml 的 id 字段后重新部署。
    4. 
    

    
KV 绑定成功后，首次访问会自动写入一份空配置，之后所有节点都由你在控制台维护。
